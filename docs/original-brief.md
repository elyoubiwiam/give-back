# Give Back

Want to build : 

- Product, called "GiveBack" for now, for micro-events, volunteers helping charities, ngos, for small tasks when they just need hands on
- a gamification process, the more tasks you do, the more points you get
- rewards : discounts in partnered coffees, shops, events etc...
- ranking system, not individual, but "looks how people are giving back to the community in your city" with examples of latest actions made
- app would be based in UK , choose city based on available charities.
- account system, setup everything but dont activate now, will come later on, but basically you create your profile, with types of actions you're able to do, how you can help, also add the possibility to donate money within the app, so setup Stripe payment as well, not working connection yet but the fact that it would be, possible to do 
- UX should be minimal, clean, warm colours

Task filtering and profile preferences:
Filter tasks by both time and cause. The causes should be tailored to the ones the user has specified matters to them, and the time should be tailored from the allocated time they're willing to give for the tasks; make them choose that when they're creating their profiles.
